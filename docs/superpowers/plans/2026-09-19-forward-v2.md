# 端口转发 v2 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 v1「按入站绑 socks5/http 出口」基础上，加域名白名单（全局 + 节点三态）、代理健康检查（出口 IP/地区/延迟 + TG 告警）、供应商到期提醒、客户端一键续费。

**Architecture:** 只扩 `forward_rules` 一张表；两个全局设置走 3x-ui `settings` 键值表；注入逻辑扩展 v1 的 `injectForwardRules`；健康检查用 Go 标准库 `net/http` + `Proxy` 走代理请求 IP 查询接口；两个 cron job（10 分钟检查 / 每日到期）；续费复用上游 `bulkAdjust`。

**Tech Stack:** Go 1.27 / gin / gorm(sqlite) / robfig cron；React 19 / antd 5 / TanStack Query / vitest / dayjs。

**前置（已完成）：** main 已合并上游 `MHSanaei/3x-ui@main`（2026-09-19），`feat/port-forward` 已 rebase，go build / go test / tsc / vitest / lint / vite build 全部通过。

```go
// splitDomains: 按行拆、trim、去空行、去重，保持顺序

// effectiveDomains: 节点三态；返回 nil 表示不限制
func effectiveDomains(rule model.ForwardRule, global []string) []string {
	if !rule.DomainLimit { return nil }
	if own := splitDomains(rule.Domains); len(own) > 0 { return own }
	return global
}
```

```ts
// 返回需要给 bulkAdjust 的 addDays；expiryTime<=0 返回 null（不可续）
export function renewAddDays(expiryTime: number, months: number, now: number): number | null {
  if (expiryTime <= 0) return null;
  const base = Math.max(expiryTime, now);
  const target = dayjs(base).add(months, 'month').valueOf();
  return Math.ceil((target - expiryTime) / 86_400_000);
}
```
